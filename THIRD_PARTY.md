# Third-party software and assets

All of these are used as dependencies (installed by a package manager or by the vendor's installer). None of their source code is copied into this repo.

| Component | Use | Licence |
|---|---|---|
| [Physical AI Studio](https://github.com/open-edge-platform/physical-ai-studio) (Intel) | recording, training, export of policies; its runtime session runs the cell's policies | Apache-2.0 |
| [OpenVINO Physical AI runtime (`physicalai`)](https://github.com/openvinotoolkit/physicalai) (Intel) | runs the exported policies (inside Studio) | Apache-2.0 |
| [OpenVINO](https://github.com/openvinotoolkit/openvino) (Intel) | inference on CPU/GPU/NPU; `tools/policy_tune.py` edits exported graphs | Apache-2.0 |
| [Anomalib](https://github.com/openvinotoolkit/anomalib) (Intel) | defect (anomaly) detection: PatchCore / EfficientAd training and OpenVINO export | Apache-2.0 |
| ImageNet-pretrained backbones (via Anomalib / timm / torchvision, e.g. `wide_resnet50_2`) and EfficientAd's pretrained weights | anomaly-model feature extractors, downloaded at training time, not redistributed here | weights under their providers' terms (ImageNet terms of use) |
| [Imagenette](https://github.com/fastai/imagenette) (fast.ai) | EfficientAd training needs it; downloaded at training time, gitignored, not redistributed | Apache-2.0 (images: ImageNet terms) |
| [LeRobot](https://github.com/huggingface/lerobot) (Hugging Face) | SO-101 calibration and teleoperation | Apache-2.0 |
| [PyTorch](https://pytorch.org) / torchvision | training backend (through Studio and Anomalib) | BSD-3-Clause |
| [OpenCV](https://opencv.org) | image processing, ArUco markers | Apache-2.0 |
| [NumPy](https://numpy.org) / [SciPy](https://scipy.org) / [pandas](https://pandas.pydata.org) | arrays, fits, dataset (parquet) reading | BSD-3-Clause |
| [Matplotlib](https://matplotlib.org) | plots | Matplotlib licence (PSF-style, BSD-compatible) |
| [Pillow](https://python-pillow.org) | image files | MIT-CMU (HPND) |
| [pyserial](https://github.com/pyserial/pyserial) | Feetech servo bus access (scan, IDs, registers) | BSD-3-Clause |
| [aiohttp](https://github.com/aio-libs/aiohttp) | websocket client to Studio's runtime session | Apache-2.0 |
| [Atech SDK (`atech`)](https://github.com/atechdotdev/python-sdk) | conveyor motor board (the belt was dropped on Sat; `belt/` is kept for history). `belt/AGENTS.md` and `belt/CLAUDE.md` are generated by its `atech new` command. | MIT |
| [Modal](https://modal.com) / Verda | cloud GPU training (through Physical AI Studio's remote trainers) | services; Modal client Apache-2.0 |
| [SO-ARM100 / SO-101](https://github.com/TheRobotStudio/SO-ARM100) (TheRobotStudio) | robot arm hardware design | Apache-2.0 |
