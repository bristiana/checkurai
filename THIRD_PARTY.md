# Third-party software and assets

All of these are used as dependencies (installed by a package manager or by the vendor's installer). None of their source code is copied into this repo.

| Component | Use | Licence |
|---|---|---|
| [Physical AI Studio](https://github.com/open-edge-platform/physical-ai-studio) (Intel) | recording, training, export of policies | Apache-2.0 |
| [OpenVINO Physical AI runtime (`physicalai`)](https://github.com/openvinotoolkit/physicalai) (Intel) | running exported policies on the robot; cameras; SO-101 URDF used for the 3D twin | Apache-2.0 |
| [OpenVINO](https://github.com/openvinotoolkit/openvino) / [NNCF](https://github.com/openvinotoolkit/nncf) (Intel) | inference on CPU/GPU/NPU, weight compression | Apache-2.0 |
| [Anomalib](https://github.com/openvinotoolkit/anomalib) (Intel) | defect (anomaly) detection | Apache-2.0 |
| [LeRobot](https://github.com/huggingface/lerobot) (Hugging Face) | SO-101 calibration and teleoperation | Apache-2.0 |
| [Rerun](https://github.com/rerun-io/rerun) | 3D twin and monitoring viewer | Apache-2.0 |
| [PyTorch](https://pytorch.org) | training backend | BSD-3-Clause |
| [OpenCV](https://opencv.org) | image processing | Apache-2.0 |
| [Intel RealSense SDK (`pyrealsense2`)](https://github.com/IntelRealSense/librealsense) | depth camera | Apache-2.0 |
| [Atech SDK (`atech`)](https://github.com/atechdotdev/python-sdk) | conveyor motor board firmware and control. `belt/AGENTS.md` and `belt/CLAUDE.md` are generated by its `atech new` command. | MIT |
| [Modal](https://modal.com) client | cloud GPU training (through Physical AI Studio) | Apache-2.0 |
| [SO-ARM100 / SO-101](https://github.com/TheRobotStudio/SO-ARM100) (TheRobotStudio) | robot arm hardware design | Apache-2.0 |
| "Conveyor Generator" 3D model (MakerWorld) | printed conveyor belt | personal use only; the print files are **not** in this repo |
